# Interpolación Polinomial - Métodos Numéricos (ITSX)

Este repositorio contiene la implementación en Java de dos métodos fundamentales de interpolación numérica:
1. *Diferencias Divididas de Newton* (Código base analizado)
2. *Polinomios de Lagrange* (Rutina completada e integrada)

## Requerimientos del Entorno
* *Lenguaje:* Java 17 o superior.
* *IDE Recomendado:* IntelliJ IDEA, NetBeans o Eclipse.
* *Gestor de dependencias / Compilación:* Java nativo o Maven (opcional).

## Estructura del Proyecto
* src/interpolacion/InterpolacionLagrange.java: Clase que contiene la lógica resuelta del método de Lagrange.
* src/interpolacion/InterpolacionNewton.java: Clase con el método de Diferencias Divididas de Newton.
* src/interpolacion/Main.java: Clase principal para ejecutar los casos de prueba por consola.

## Instrucciones de Ejecución Rápida
1. Clonar el repositorio: git clone <URL_DE_TU_REPOSITORIO>
2. Abrir el proyecto en tu IDE preferido.
3. Ejecutar la clase Main.java para visualizar los resultados
